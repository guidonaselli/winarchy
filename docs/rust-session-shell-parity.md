# Explorer-free session shell parity contract

## Scope

This contract compares Winarchy's current Explorer-based session with an opt-in session where `winarchy-shell.exe --session-shell` replaces Explorer as the interactive shell. It covers the existing Rust shell, AHK hotkeys, komorebi, and Winarchy commands. The separate Files feature is out of scope.

“Expected behavior” is the acceptance target. The evidence column distinguishes source/tests from runtime proof; source coverage alone does not establish parity.

| Area | Expected user flow and acceptance | Required fallback | Evidence status |

Return starts Explorer, waits for an Explorer-owned responsive `Shell_TrayWnd`, then exits Winarchy. A crash or hung shell must recover to Explorer without stopping AHK first. | Bounded AHK watchdog invokes the PowerShell recovery bridge; if recovery fails, keep AHK/services alive and expose maintenance rollback. Never leave a blank desktop by force-exiting the only shell. | Manual Sandbox sign-in/return is recorded for prior current builds. Current AHK timer-to-bridge crash recovery remains open. ## Runtime test record format

For each supported row, record build/hash, Sandbox or hardware environment, exact steps, observed result, fallback result, screenshot/log, and whether another Explorer process was present. A row stays open when only source inspection or unit tests exist. Do not use Sandbox results as performance claims.
